# Ave Mujica Source Material

Writing style lives in [content/posts/AGENTS.md](../../AGENTS.md), format and typography in [content/AGENTS.md](../../../AGENTS.md).

Research material sits in `_materials/`, private to the build. Each file carries a caution about how far it can be pushed.

| File                      | Use                                              | Caution                                                     |
| ------------------------- | ------------------------------------------------ | ----------------------------------------------------------- |
| `translation-glossary.md` | Canonical names for people, bands, and terms     | Use the canonical form; short forms are allowed             |
| `plot.md`                 | Factual basis for the Ave Mujica plot            | Plain statement of events, so supply your own reading       |
| `mygo-plot.md`            | Member backstory and the origin of the relations | The two works stand apart, so do not map one onto the other |
| `plot-theories*.md`       | Audience readings, as a prompt for thinking      | Unofficial, so keep fact and hypothesis apart               |
| `staff-talk.md`           | Creative intent and technical detail             | Authorial intent ≠ the sole source of a work's meaning      |
| `_characters/*.md`        | Background, relations, psychological state       | Avoid reducing a character to a label                       |
| `_songs/*.md`             | Japanese lyrics with Chinese translation         | Read against plot context and watch for double meaning      |
